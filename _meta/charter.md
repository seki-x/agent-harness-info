# Knowledge Base Charter

## Mission

Maintain a continuously revised, evidence-backed map of the current state of
AI Agent and Agent Harness engineering.

The knowledge base should help an experienced software engineer understand:

- durable engineering problems in the field;
- important solution patterns;
- trade-offs among those patterns;
- relationships between concepts;
- practices becoming established;
- formerly useful ideas becoming obsolete.

## Canonical language

English is the canonical source language. Translations are derived outputs and
must never become an independent source of truth.

## Audience

The primary audience is technically experienced readers with working knowledge
of LLMs, software engineering, and agent systems. Prefer precise engineering
explanations over introductory marketing language.

## Scope

The initial scope is:

    AI Agent and Agent Harness engineering

The exact taxonomy is intentionally unspecified before bootstrap. Bootstrap
must discover the problem space before defining the initial taxonomy.

## Non-goals

This project is not:

- a chronological AI news feed;
- an exhaustive list of vendors or products;
- an exhaustive paper index;
- a release-note mirror;
- a collection of every experimental agent idea;
- a leaderboard or benchmark tracker unless it materially changes engineering
  understanding.

## Desired knowledge properties

Canonical knowledge should be current, useful, evidence-backed, low-noise,
concept-oriented, explicit about uncertainty, easy to refactor, understandable
without following weekly news, and reasonably independent of vendors and
frameworks.

## Knowledge states

Canonical pages may use:

- core — sufficiently established for the normal engineering model;
- emerging — important and credible, but not yet stable;
- deprecated — retained temporarily because the superseded concept remains
  useful for history, migration, or transition.

Ideas with insufficient evidence belong in watchlist/.

## Governing principle

The repository should answer:

    What should a technically serious reader believe and understand about this
    field now?

It should not merely answer:

    What happened recently?
