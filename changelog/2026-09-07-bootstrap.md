# Bootstrap — 2026-09-07

## Summary

Initialized the first current knowledge state around five durable problem domains: execution and control; context and memory; action and integration; security and human control; evaluation and operations. The state contains 17 substantive pages (16 core, 1 emerging) plus the preserved structural entry page. It is a candidate for review, not a frozen release.

## Canonical changes

The model distinguishes model proposals from executed effects, working context from durable task state and cross-task memory, and authored procedures from retained experience. It treats tools as validated action contracts, security as enforced authority plus handling of untrusted inputs, and evaluation as outcome evidence rather than fluent output or successful transport.

Control-flow plans and failure transitions, context compaction, memory subtypes and protocol examples remain sections of their parents. Independent trade-off spaces—recovery, coordination, retrieval, memory lifecycle, authored procedures, interoperability, isolation, oversight, evaluation, observability and budgets—receive child pages. Substantive parent indexes preserve containment and use links for dependencies.

## Maturity and watchlist

Reusable procedures is emerging because activation, packaging and host behavior are not uniformly established. Coordination and interoperability are core problems with medium-confidence syntheses and explicitly unsettled implementations; no universal multi-agent superiority or protocol-level task portability is asserted.

Added two watch entries: open-ended self-modifying harnesses and universal portable agent telemetry semantics. These were evaluated, not copied from an unreviewed submission. No existing concept was deprecated or removed.
